# Customer Shopping Behaviour Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behaviour to uncover insights into purchasing patterns, customer segmentation, product performance, discount usage, subscription trends, and revenue contribution.

Using **Python, Pandas, PostgreSQL, SQL, and Power BI**, the project combines data cleaning, exploratory data analysis, business-focused SQL queries, and interactive dashboard visualization to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze customer spending patterns across different demographics.
- Compare revenue generated by male and female customers.
- Identify the impact of discounts and shipping methods on purchase amounts.
- Evaluate product performance using customer review ratings and purchase frequency.
- Compare spending behaviour between subscribers and non-subscribers.
- Segment customers based on their previous purchase history.
- Analyze revenue contribution across different age groups.
- Present key business insights through a Power BI dashboard.

## 🛠️ Tech Stack

- **Python:** Data cleaning, preprocessing, and exploratory data analysis.
- **Pandas:** Data manipulation, transformation, and feature engineering.
- **Jupyter Notebook:** Interactive analysis and documentation.
- **PostgreSQL:** Database management and analytical queries.
- **SQL:** Aggregations, filtering, subqueries, Common Table Expressions (CTEs), CASE statements, and window functions.
- **Power BI:** Interactive dashboard development and data visualization.

## 📊 Dataset Description

The dataset contains **3,900 customer records and 18 original columns** describing customer demographics, purchases, preferences, and shopping habits.

Key attributes include:

| Category | Attributes |
|---|---|
| Customer Details | Customer ID, Age, Gender, Location |
| Purchase Information | Item Purchased, Category, Purchase Amount |
| Product Preferences | Size, Color, Season, Review Rating |
| Customer Loyalty | Subscription Status, Previous Purchases |
| Promotions | Discount Applied, Promo Code Used |
| Transaction Preferences | Shipping Type, Payment Method |
| Shopping Frequency | Frequency of Purchases |

The analysis also creates additional features, including age groups and purchase frequency in days.

## 🔍 Project Workflow

### 1. Data Loading and Exploration

- Imported the dataset using Pandas.
- Examined the first few records and dataset structure.
- Used descriptive statistics to understand numerical and categorical variables.
- Checked for missing values and reviewed data quality.

### 2. Data Cleaning and Feature Engineering

- Handled missing review ratings by imputing category-wise median values.
- Standardized column names to lowercase and snake_case format.
- Created age groups using quartile-based binning.
- Converted purchase frequency categories into approximate day intervals.
- Removed the promo code column after checking its relationship with discount usage.

### 3. SQL Analysis Using PostgreSQL

Loaded the processed dataset into PostgreSQL and wrote queries to answer business questions, including:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent at least the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express Shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which five products have the highest percentage of purchases with discounts?
7. How can customers be segmented into New, Returning, and Loyal categories?
8. What are the top three most purchased products within each category?
9. Are repeat buyers with more than five previous purchases likely to subscribe?
10. How much revenue does each age group contribute?

### 4. Power BI Dashboard

Developed a Power BI dashboard to present customer shopping insights visually and make the findings easier to interpret.

The dashboard complements the Python and SQL analysis by providing a visual overview of customer behaviour and business performance.

## 🚀 How to Run the Project

### Prerequisites

Install Python, Jupyter Notebook, and PostgreSQL. Power BI Desktop is required to open the dashboard.

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
cd Customer-Shopping-Behaviour-Analysis
```

### Step 2: Install Python Dependencies

```bash
pip install pandas sqlalchemy psycopg2-binary notebook
```

### Step 3: Run the Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_shopping_behaviour_analysis.ipynb` and execute the cells in order.

### Step 4: Configure PostgreSQL

- Create a database named `customer_behavior`.
- Update the database connection settings in the notebook with your own PostgreSQL credentials and port.
- Execute the notebook cells to load the processed dataset into a table named `customer`.

**Security note:** Do not upload database passwords or other credentials to GitHub. Use environment variables or a local configuration file excluded through `.gitignore`.

### Step 5: Execute SQL Queries

Open `customer_behavior.sql` in pgAdmin or another PostgreSQL client connected to the correct database. Run the queries to explore customer behaviour and business performance.

### Step 6: Open the Power BI Dashboard

Open `Customer_behavior_dashboard.pbix` in Power BI Desktop to explore the dashboard.
